환불은 표시 가격이 아닌 할인·부가세 등을 반영한 실제 결제액을 기준으로 합니다.

2. 월 구독 해지

  • 다음 결제 중단: 해지 신청 접수 후 다음 정기결제를 중단합니다. 현재 결제한 기간의 마지막 날까지 이용하며 해당 기간 만료 시 종료됩니다.
  • 즉시 해지·환불: 즉시 종료를 요청하면 접수 시각을 기준으로 이용 종료와 아래 환불 규정을 적용합니다.
  • 다음 결제 예정 시각 전에 접수된 해지 요청은 다음 결제에 반영합니다. 처리 지연으로 접수 후 정기결제가 발생하면 해당 결제를 전액 취소합니다.
  • 별도 해지 위약금은 없습니다. 구독 종료 후 추가 이용권을 사용할 수 없으면 남은 유료 통화분도 아래 기준으로 환불합니다.

3. 월 구독 환불

서비스 제공 시작 전 취소는 전액 환불합니다. 시작 후 즉시 해지는 결제 주기의 남은 기간을 일할 계산해 환불합니다.

환불액 = 실제 월 결제액 × 미사용 일수 ÷ 해당 결제 주기의 전체 일수

제공 시작일부터 즉시 해지 접수일까지를 이용일로 계산하며, 접수 다음 날부터 결제 주기 마지막 날까지가 미사용 일수입니다. 원 미만은 고객에게 유리하게 올림하고 환불액은 실제 결제액을 초과하지 않습니다.

예: 스탠다드 38,500원, 전체 30일 중 미사용 15일이면 19,250원 환불.

월 포함 통화는 별도 현금 상품이 아니므로 미사용 통화 수를 추가로 현금 환산하지 않습니다. 제공된 월 포함 통화에 대한 별도 차감 없이 기간 기준으로 정산합니다.

4. 추가 통화 이용권 환불

  • 미사용 이용권: 실제 결제액 전액 환불.
  • 일부 사용 이용권: 남은 유료 통화 수에 비례하여 환불. 무료·보너스 통화는 환불 금액에 포함하지 않습니다.
  • 3개월은 통화 사용 가능 기간입니다. 기간이 지났다는 이유만으로 유료 미사용분의 환불을 일괄 거절하지 않으며, 동일한 잔여 통화 기준으로 정산합니다.
환불액 = 실제 이용권 결제액 × 남은 유료 통화 수 ÷ 구매한 유료 통화 수

예: 실제 결제액 300,000원인 356통 이용권에서 178통이 남았다면 150,000원 환불.

통화 차감은 실제 이용 내역을 확인합니다. 연결 실패 또는 시스템 오류로 잘못 차감한 통화는 복구 후 계산하며, 원 미만은 올림합니다.
